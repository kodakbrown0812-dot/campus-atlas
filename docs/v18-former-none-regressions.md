# V1.8 former-None regression classifications

The old `None` delivery level represented two materially different states. V1.8 removes that ambiguity without mechanically relabeling results.

## A. Enough source-grounded continuity exists → Light

- A transferred room has one accepted governing statement tied to its canonical case, even when the continuation task is self-contained or uses different wording.
- A presentation or transfer preference has one safe governing match and no linked correction, conflict, counterevidence, or protected sensitivity.
- A task has one directly applicable approved mechanism and broad reconstruction is unnecessary.

These cases now create an immutable Light packet and receipt. They do not return a session-only capsule.

## B. Established continuity is insufficient → clarification or safe failure

- The project has no approved State Truth that applies to the task.
- The only apparent statement is proposed, rejected, retired, superseded, or outside the selected project boundary.
- A project-scoped task cannot be tied truthfully to one current governed state cluster.

These cases return clarification or another existing safe failure. Atlas does not create a packet and does not invent continuity.

Medium is introduced only for several related governed State Truth items whose relationships matter but do not require broad project reconstruction. Full remains responsible for broad, corrected, conflicted, sensitive, or multi-cluster state.
