# Campus Atlas V1.7 hosted release checklist

## Status

This checklist is prepared but **not completed**. Slice 6C made no hosted
deployment and did not mutate production infrastructure.

Local contracts and browser checks are necessary but do not establish hosted
release acceptance.

## Release identity

- [ ] Record reviewed PR and merge commit.
- [ ] Record the exact deployed commit.
- [ ] Confirm deployment is built from that commit.
- [ ] Record hosted environment and URL.
- [ ] Confirm the environment is not an unlabeled fixture/test deployment.

## Configuration and secrets

- [ ] Configure canonical D1 binding `DB`.
- [ ] Configure the canonical write-authorization secret.
- [ ] Configure `OPENAI_API_KEY` when real receiving-model handoff is required.
- [ ] Confirm secrets are not rendered, logged, committed, or stored in
  browser storage.
- [ ] Confirm no test receiving-model adapter is enabled in production.
- [ ] Confirm public demo behavior remains isolated and fail-closed.

Do not record secret values in release evidence.

## D1 migration and canonical ownership

- [ ] Back up or otherwise preserve the current restore point.
- [ ] Apply all reviewed D1 migrations in order.
- [ ] Verify migration status in the hosted database.
- [ ] Verify immutable/version triggers are present.
- [ ] Verify V1.7 reads use canonical tables.
- [ ] Verify new conversations, findings, governance, mechanisms, packets,
  receipts, handoffs, and answers write only through canonical services.
- [ ] Verify legacy `AtlasState` is read-only for rollback/history.
- [ ] Confirm no second writable authority remains.

## Health and failure honesty

- [ ] Hosted `/api/v1/health` reports the real canonical state.
- [ ] Loading is distinguishable from connected.
- [ ] D1 unavailability displays canonical-state unavailable.
- [ ] Persistence failure remains visible.
- [ ] Unauthorized sessions remain visibly read-only.
- [ ] Missing state, unsafe packet, and provider failure remain failures.
- [ ] No seeded project, finding, answer, or England–Ghana fallback appears.
- [ ] No failure is displayed as success.

## Project and public isolation

- [ ] Direct Project A record links fail in Project B.
- [ ] Project switching clears selected conversations, findings, cases,
  mechanisms, packet/handoff detail, and local drafts.
- [ ] Active conversations restore only within their owning project.
- [ ] Semantic similarity cannot cross the project boundary.
- [ ] Public/demo workspaces cannot access private canonical state.
- [ ] Public/demo writes cannot reach production canonical records.
